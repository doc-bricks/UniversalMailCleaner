# Universal Mail Cleaner - Store Assets

Dieses Verzeichnis enthält die standardisierten Kachel- und Anwendungs-Assets für die Paketierung im Microsoft Store und Windows App Installer (MSIX / MSI / WinGet).

## Spezifikation der enthaltenen Assets

| Datei | Abmessungen | Typ | Verwendungszweck |
|---|---|---|---|
| `icon_44x44.png` / `Square44x44Logo.png` | 44x44 px | RGBA PNG | App-Listen-Icon, Taskleiste und Windows-Startmenü |
| `icon_50x50.png` / `StoreLogo.png` | 50x50 px | RGBA PNG | Store-Katalog-Logo |
| `icon_150x150.png` / `Square150x150Logo.png` | 150x150 px | RGBA PNG | Mittlere Startmenü-Kachel |
| `icon_310x310.png` / `Square310x310Logo.png` | 310x310 px | RGBA PNG | Große Startmenü-Kachel |
| `icon_310x150.png` / `Wide310x150Logo.png` | 310x150 px | RGBA PNG | Breite Startmenü-Kachel mit zentriertem Markenemblem |

Alle Assets wurden aus dem hochauflösenden 1024x1024 Master-Icon generiert und entsprechen den Transparenz- und Farbrichtlinien von Windows 10/11.
